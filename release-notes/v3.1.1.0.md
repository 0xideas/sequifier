# Sequifier v3.1.1.0

This release adds embedding output for prediction-aligned inference. The
comparison baseline is v3.1.0.0.

## Highlights

- **Infer embeddings from prediction-aligned splits.** Set
  `model_type: embedding` to obtain embeddings at the configured prediction
  positions. Aligned embeddings are labeled with the target `itemPosition` and
  positions outside the split are omitted. For a causal model with
  `target_offset: 1`, the embedding labeled as row N represents the context
  used to predict row N; it does not include that row's value.
- **Keep input-position labels on other splits.** Embeddings from splits that
  are not prediction-aligned continue to be labeled by their input activation
  positions.
- **Correct package license metadata.** The package now declares
  `Apache-2.0`, matching the repository's existing LICENSE file. The license
  text itself has not changed.

## Configuration and compatibility

- Prediction-aligned inference still requires `window_stride: null` and does
  not support autoregressive generation.
- Embedding consumers should account for target-position labels and split
  masking on aligned splits. No preprocessing or configuration migration is
  required.

See the [preprocessing guide](../documentation/configs/preprocess.md) and
[inference guide](../documentation/configs/infer.md) for aligned output details.
